# گالری صنوبر

فروشگاه اینترنتی اسباب‌بازی با طراحی فارسی و راست‌چین، ساخته‌شده با HTML، CSS و JavaScript خالص.

## اجرا

فایل `index.html` را در مرورگر باز کنید.

## انتشار با GitHub Pages

در مخزن GitHub به مسیر **Settings → Pages** بروید، در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید، سپس Branch را روی `main` و پوشه را روی `/ (root)` قرار دهید و Save را بزنید.

پس از فعال‌شدن Pages، آدرس سایت معمولاً این خواهد بود:
`https://mon9900mr.github.io/galerysenobar/`

## نکته‌های پیش از فروش واقعی

- شماره تلفن و ایمیل نمونه را با اطلاعات واقعی فروشگاه جایگزین کنید.
- قیمت‌ها و تصاویر فعلی نمونه هستند و باید با محصولات واقعی هماهنگ شوند.
- سبد خرید در مرورگر کار می‌کند؛ برای ثبت سفارش واقعی، پرداخت آنلاین و مدیریت سفارش‌ها به بک‌اند و درگاه پرداخت نیاز است.
