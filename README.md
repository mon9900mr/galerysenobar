# NARA COLLECTION | نارا کالکشن

فروشگاه فارسی و راست‌چین لباس‌های راحتی و خانگی زنانه، ساخته‌شده با HTML، CSS و JavaScript.

## دسته‌بندی‌ها
- ست تیشرت و شلوار راحتی
- ست بلوز و شلوار خانگی
- تیشرت و تاپ
- شلوار راحتی
- لباس خواب و خانگی
- هودی و دورس
- روبدوشامبر و لباس نخی

## امکانات
فروشگاه، جست‌وجو و فیلتر محصولات، سبد خرید، ثبت درخواست سفارش، ورود و حساب کاربری آزمایشی، پنل مالک و ادمین، مدیریت محصولات و دسته‌بندی‌ها، مدیریت سفارش‌ها و مشتریان، تنظیمات محتوای سایت و حالت روشن/تاریک.

## اجرا
فایل `index.html` را باز کنید یا در GitHub به مسیر **Settings → Pages** بروید و منبع انتشار را روی شاخه `main` و پوشه `/ (root)` قرار دهید.

## محدودیت‌های نسخه نمایشی
- ورود فعلی فقط نقش را با `sessionStorage` شبیه‌سازی می‌کند؛ احراز هویت واقعی و کنترل دسترسی سمت سرور وجود ندارد.
- محصولات و تنظیمات در `localStorage` همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها یا کاربران مشترک نیستند.
- ثبت سفارش واقعی، پرداخت آنلاین و اتصال به پایگاه داده هنوز پیاده‌سازی نشده‌اند.
- GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند و امکان اجرای PHP یا پایگاه داده را ندارد.

برای استفاده عملی فروشگاه، باید بک‌اند امن با احراز هویت سمت سرور، کنترل مجوزها در API و پایگاه داده راه‌اندازی شود.
