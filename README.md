# گالری سنوبر

فروشگاه فارسی و راست‌چین تخصصی اسباب‌بازی، ساخته‌شده با HTML، CSS و JavaScript.

## ساختار پروژه

```text
galerysenobar/
├── index.html
├── category.html
├── products.html
├── login.html
├── admin.html
├── admin-panel.html
├── owner.html
├── user-panel.html
├── assets/
│   ├── css/
│   │   └── theme-toys.css
│   ├── js/
│   │   ├── store-data.js
│   │   └── theme-toys.js
│   └── images/
│       └── toys/
│   └── images/ (مسیر نگهداری تصاویر واقعی فروشگاه)

## اجرا

فایل `index.html` را باز کنید یا در GitHub به مسیر **Settings → Pages** بروید و منبع انتشار را روی شاخه `main` و پوشه `/ (root)` قرار دهید.

## محدودیت‌های نسخه نمایشی

- ورود فعلی فقط نقش را با `sessionStorage` شبیه‌سازی می‌کند؛ احراز هویت واقعی و کنترل دسترسی سمت سرور وجود ندارد.
- محصولات و تنظیمات در `localStorage` همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها یا کاربران مشترک نیستند.
- ثبت سفارش واقعی، پرداخت آنلاین و اتصال به پایگاه داده هنوز پیاده‌سازی نشده‌اند.
- GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند و امکان اجرای PHP یا پایگاه داده را ندارد.

برای استفاده عملی فروشگاه، باید بک‌اند امن با احراز هویت سمت سرور، کنترل مجوزها در API و پایگاه داده راه‌اندازی شود. رمزهای عبور باید به‌صورت امن هش شوند و نقش مالک تنها از سمت سرور تعیین شود.


## فرم ورود و نشانی

فرم یکپارچه ورود/ثبت‌نام شامل نام، نام خانوادگی، شماره موبایل، کد پستی و انتخاب نشانی روی نقشه است. نقشه از Leaflet و داده‌های OpenStreetMap استفاده می‌کند و جست‌وجو/نشانی معکوس از سرویس عمومی Nominatim انجام می‌شود. ارسال کد پیامکی عمداً غیرفعال است.

**مهم:** چون سایت فعلاً روی GitHub Pages و بدون بک‌اند اجرا می‌شود، فرم فقط اعتبارسنجی سمت مرورگر را انجام می‌دهد و اطلاعات شخصی را ذخیره یا ارسال نمی‌کند. شماره مالک در فایل‌های عمومی فرانت‌اند قرار داده نشده است. برای فعال‌سازی حساب مالک و تعیین نقش ادمین باید شماره مالک در تنظیمات خصوصی سرور ثبت شود و نقش فقط پس از احراز هویت در بک‌اند تعیین گردد؛ هرگز نقش را از localStorage/sessionStorage یا ورودی فرم نپذیرید.
