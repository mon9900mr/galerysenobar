# گالری صنوبر

فروشگاه فارسی و راست‌چین تخصصی اسباب‌بازی، با HTML، CSS و JavaScript.

## اجرا
فایل `index.html` را باز کنید یا GitHub Pages را برای شاخه `main` و پوشه ریشه فعال کنید.

## صفحات
- `index.html`: صفحه اصلی فروشگاه
- `category.html`: دسته‌بندی اسباب‌بازی‌ها
- `products.html`: فهرست و فیلتر محصولات
- `admin.html`: پنل مدیریت محلی، محصولات و ویرایش متن/تصویر پیش‌فرض سایت
- `store-data.js`: داده‌های اولیه و دسته‌بندی‌های فروشگاه

## نکته مهم درباره نسخه GitHub Pages
این نسخه فرانت‌اند است. پنل ویرایش و محصولات در `localStorage` همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها یا کاربران مشترک نیستند. صفحه ویرایش مالک در این مرحله قفل ورود امن ندارد؛ بنابراین هنوز نباید برای مدیریت عمومی روی اینترنت استفاده شود. GitHub Pages نمی‌تواند PHP یا دیتابیس اجرا کند.

برای فروش واقعی، پس از تهیه هاست باید بک‌اند PHP + MySQL، ورود امن، نقش‌های `OWNER` و `ADMIN` و `USER`، مجوزدهی سمت سرور، ثبت سفارش و درگاه پرداخت پیاده‌سازی شوند. اطلاعات قیمت، موجودی، تماس و مشخصات واقعی محصولات باید توسط مالک وارد شوند؛ قیمت و موجودی ساختگی در کاتالوگ پیش‌فرض نمایش داده نمی‌شود.

## تصاویر
تصاویر فعلی فقط برای پیش‌نمایش دسته‌بندی‌ها و نمونه چیدمان استفاده شده‌اند. پیش از فروش عمومی، تصاویر مجاز و واقعی هر محصول را جایگزین کنید.
