# گالری صنوبر

فروشگاه فارسی و راست‌چین تخصصی اسباب‌بازی، با HTML، CSS و JavaScript.

## اجرا
فایل `index.html` را باز کنید یا GitHub Pages را برای شاخه `main` و پوشه ریشه فعال کنید.

## صفحات فروشگاه و پنل‌ها
- `index.html`: صفحه اصلی فروشگاه
- `category.html`: دسته‌بندی اسباب‌بازی‌ها
- `products.html`: فهرست و فیلتر محصولات
- `login.html`: صفحه ورود و انتخاب نقش نمایشی برای پیش‌نمایش پنل‌ها
- `owner.html`: پنل مالک با دسترسی کامل به بخش‌های فعلی مدیریت و ویرایش محتوای سایت
- `admin-panel.html`: پنل جداگانه ادمین برای مدیریت کاتالوگ و مشاهده سفارش‌های محلی
- `user-panel.html`: پنل مشتری برای پروفایل و سفارش‌های خودش
- `admin.html`: مسیر هدایت خودکار بر اساس نقش انتخاب‌شده
- `store-data.js`: داده‌های اولیه و دسته‌بندی‌های فروشگاه

## محدودیت امنیتی مهم نسخه GitHub Pages
دکمه‌های ورود فعلی فقط نقش‌ها را برای پیش‌نمایش رابط کاربری در `sessionStorage` شبیه‌سازی می‌کنند. این ورود واقعی نیست و هیچ‌کدام از صفحات را در برابر کاربر فنی محافظت نمی‌کند؛ نقش را می‌توان در مرورگر دستکاری کرد. به همین دلیل این نسخه برای مدیریت عمومی یا نگهداری اطلاعات حساس امن نیست.

پس از تهیه هاست باید احراز هویت واقعی در بک‌اند PHP + MySQL ساخته شود: سرور نقش حساب را پس از ورود برگرداند، همه مجوزها در هر API سمت سرور بررسی شوند، مالک تنها فرد مجاز برای مدیریت ادمین‌ها و نقش‌ها باشد، و رمزها به‌صورت امن هش شوند. GitHub Pages نمی‌تواند PHP یا دیتابیس اجرا کند.

## ذخیره‌سازی
در نسخه پیش‌نمایش، محصولات و تنظیمات در `localStorage` همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها یا کاربران مشترک نیستند. سفارش واقعی، مشتری واقعی و پرداخت آنلاین هنوز پیاده‌سازی نشده‌اند.

## تصاویر و داده‌های نمونه
تصاویر فعلی برای پیش‌نمایش چیدمان هستند. قیمت و موجودی واقعی باید توسط فروشگاه وارد شوند؛ داده ساختگی نباید به مشتری نمایش داده شود.
