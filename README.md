# NARA COLLECTION | نارا کالکشن

فروشگاه لباس‌های راحتی و خانگی زنانه، با رابط فارسی و راست‌چین.

## وضعیت پروژه
- رابط فعلی GitHub Pages برای پیش‌نمایش طراحی است.
- زیرساخت بک‌اند PHP و دیتابیس MySQL در پوشه `backend/` اضافه شده است.
- صفحه ثبت‌نام و ورود به API سمت سرور متصل شده‌اند؛ حساب مالک باید با اسکریپت CLI ایجاد شود.
- تا تکمیل اتصال پنل‌های مدیریت، محصولات، تنظیمات، تصاویر و گردش سفارش به API، نسخه GitHub Pages را برای دریافت سفارش و پرداخت واقعی فعال نکنید.

## فناوری مقصد هاست
- PHP 8.2+ با PDO MySQL
- MySQL 8+ یا MariaDB 10.5+
- HTTPS و کوکی نشست امن
- API در `backend/api/index.php`
- ساختار دیتابیس در `backend/database/schema.sql` و دسته‌بندی‌های اولیه در `backend/database/seed.sql`

## راه‌اندازی
راهنمای کامل را در `backend/README.md` و `backend/DEPLOYMENT.md` بخوانید. اطلاعات اتصال را فقط در `backend/config.php` قرار دهید؛ این فایل در Git نادیده گرفته شده و نباید منتشر شود.

## امکانات پایگاه داده
کاربران و نقش‌ها، دسته‌بندی‌ها، محصولات و محصولات ویژه، موجودی و تخفیف، محتوای سایت، هزینه‌های اضافی، سفارش‌ها، ریز اقلام، وضعیت پرداخت و گزارش رویدادهای مدیریتی.

## محدودیت مهم
GitHub Pages امکان اجرای PHP یا اتصال امن به MySQL را ندارد. داده‌های localStorage مرورگر هر بازدیدکننده جدا هستند و خودکار به دیتابیس منتقل نمی‌شوند. درگاه پرداخت هم تا انتخاب سرویس‌دهنده و پیاده‌سازی callback امن، فعال نیست.
