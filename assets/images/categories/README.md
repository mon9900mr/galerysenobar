# تصاویر دسته‌بندی گالری سنوبر

تصاویر ثابت دسته‌بندی را با نام‌های زیر در همین پوشه قرار بده. فرمت JPG، نسبت تصویر 16:9 و عرض حدود 1200 پیکسل پیشنهاد می‌شود.

- `vehicles.jpg` — ماشین و وسایل نقلیه
- `kitchen-play.jpg` — آشپزخانه و خانه‌بازی
- `building-blocks.jpg` — لگو و ساختنی
- `construction.jpg` — خانه‌سازی و سازه‌ها
- `dolls-plush.jpg` — عروسک و پولیشی
- `educational-games.jpg` — فکری و آموزشی
- `outdoor-play.jpg` — بازی‌های فضای باز
- `other-toys.jpg` — اسباب‌بازی‌های دیگر

عکس‌هایی که از پنل مالک انتخاب می‌کنی فعلاً در مرورگر همان دستگاه ذخیره می‌شوند. برای نمایش یکسان روی همه دستگاه‌ها، فایل تصویر را با نام بالا به این پوشه GitHub اضافه کن.
